# Admin Panel

## Auth
- Firebase Auth with admin custom claims.
- Dev fallback via `VITE_DEV_ADMIN_EMAIL` / `VITE_DEV_ADMIN_PASSWORD` (local only).
- See `admin-claim.md` history for claim setup.

## Admin Panel Features
- Collection CRUD via `AdminCollectionPage`.
- Form generation from `CollectionConfig`.
- Image upload via `ImageUploader` (Firebase Storage).
