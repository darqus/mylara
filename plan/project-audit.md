# Аудит проекта mylara (2026-10-20)

## Цель
Провести обзор архитектуры, качества кода, безопасности, производительности, DX и тестирования. Сформировать список улучшений с приоритетами и планом внедрения.

## Краткое состояние
- **Стек**: Quasar 2.35 / @quasar/app-vite 3.10.3, Vue 3.5, Vue Router 5, Vite 8, Vitest 5, TypeScript 5.9.3, Firebase 13, Biome (линт/формат).
- **Сборка/тесты**: `lint`, `typecheck`, `test:unit:ci` (139 тестов), `build` проходят после миграции.
- **Админка**: есть UI для CRUD по Firestore с простой парольной авторизацией.

## Важные (P1) — значительно улучшат качество
| Проблема | Описание | Рекомендации | Усложнение |
